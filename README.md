# KidZoo

A joyful place for young minds. KidZoo is a modern web application built for exploring fun, educational, and engaging content for children, including experiments, printables, and age-guided activities.

## Features

- **Explore:** Discover various categories of content designed for young minds.
- **Experiments:** Fun and safe experiments to do at home.
- **Printables:** Educational printables and worksheets.
- **Age Guide:** Filter and find content tailored for specific age groups.
- **Admin Dashboard:** Manage experiments, content, and categories.

## Tech Stack

This project is built with:

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Library:** [React](https://react.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Language:** TypeScript

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- `/app`: Contains all the routes, pages, and layouts (Next.js App Router).
- `/components`: Reusable UI components grouped by feature (e.g., `explore`, `experiments`, `printables`, `ageguide`).
